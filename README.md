# RISE Connect

**Skill-matched internships for verified students**

RISE is an internship hiring platform that puts skills first. Students verify their academic identity once through their Academic Bank of Credits (ABC) ID, match to internships based on their actual capabilities, and get ranked by assessment scores — not résumé

## What makes RISE different

- **Verify once, apply everywhere**: Students confirm their ABC ID and their institution is automatically attached
- **Skills over keywords**: Openings are ranked against existing profile skills, eliminating keyword guessing games
- **Granular assessment scores**: Short role-specific assessments score each subtopic separately with color-coded tiers (clay, amber, pine, emerald)
- **Three synchronized portals**: Students apply, organizations review ranked shortlists, and institutions monitor cohort performance — all from one shared record

## Three portals, one ecosystem

### 🎓 Lavender Portal (Students)
- One-time identity verification via ABC ID
- Skill-matched internship recommendations
- Per-subtopic assessment scorecards
- Real-time application tracking

### 🏛️ Pine Portal (Institutions)
- Live cohort dashboard across all departments
- Subtopic performance averages
- Top performer identification
- Application conversion analytics

### 🏢 Terracotta Portal (Organizations)
- Two-minute internship posting (with optional AI assistance)
- Ranked applicant tables sorted by assessment scores
- Evidence-based candidate review before résumé screening
- Skill-specific filtering and matching

## How it works

1. **Verify once**: Student confirms ABC ID, institution auto-attached
2. **Match by skill**: Internships ranked by profile skill alignment
3. **Prove it**: Role-specific assessment scores each subtopic with color-coded results
4. **Get seen**: Organizations review ranked shortlists while institutions track progress live
